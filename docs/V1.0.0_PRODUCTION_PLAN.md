## 📄 1. Pendahuluan (Pencapaian MVP)
BIZETO-Tunnel telah berhasil menyelesaikan fase **MVP (Minimum Viable Product)** dengan arsitektur yang stabil dan fungsional secara end-to-end. Fokus utama fase ini adalah membangun infrastruktur tunneling yang aman, multiplexing koneksi yang efisien, dan antarmuka manajemen berbasis data live. Seluruh komponen inti telah diuji dalam lingkungan terisolasi menggunakan Docker dan siap untuk ditingkatkan ke skala produksi.

---

## 🛠️ 2. Daftar Fitur Eksisting (Current Version)
Berikut adalah fitur-fitur yang sudah berjalan normal dan terintegrasi di fase saat ini:

### A. Core Engine & Protocol
*   **Multiplexed Tunneling:** Menggunakan protokol Yamux untuk menjalankan banyak aliran data melalui satu koneksi TCP outbound tunggal.
*   **JSON Handshake:** Protokol pertukaran data awal antara Agent dan Relay yang fleksibel untuk metadata perangkat.
*   **Auto-Reconnect:** Agent memiliki logika cerdas untuk menyambung kembali secara otomatis dengan *exponential backoff* jika koneksi terputus.

### B. Security & Identity
*   **Dynamic SSL Manager:** Integrasi otomatis dengan ACME (Let's Encrypt) yang hanya menerbitkan sertifikat untuk domain yang terdaftar di database.
*   **API Key Identity:** Manajemen identitas unik per perangkat/agent untuk autentikasi yang aman.
*   **Mock Auth Documentation:** "Pintu belakang" khusus untuk kebutuhan dokumentasi dan pengujian otomatis tanpa hambatan OAuth.

### C. Monitoring & Dashboard
*   **Live Bandwidth Tracking:** Pelacakan real-time penggunaan data (`bytes_in` dan `bytes_out`) per sesi tunnel.
*   **Unified Dashboard:** Antarmuka modern dengan **Skeleton Loaders** dan **Theme Switcher** (Dark/Light) yang menyatu di Navbar.
*   **Real-time Status Polling:** Dashboard mendeteksi koneksi fisik Agent secara otomatis melalui API status check.
*   **Owner Portal:** Panel administrasi lengkap untuk memantau kesehatan sistem, pendapatan (MRR), dan manajemen tenant (Enable/Disable User).

### D. User Experience (UX)
*   **Onboarding Terstruktur:** Panduan 4 langkah bagi pengguna baru untuk memulai (Download -> Identity -> Tunnel -> Launch).
*   **Non-Blocking Add Tunnel:** Alur pendaftaran tunnel yang fleksibel (reservasi domain dulu, jalankan agent kemudian).
*   **Auto-Config Generator:** Unduhan otomatis file `bizeto.json` yang siap pakai tanpa konfigurasi manual.

## 📈 3. Core Payment Ecosystem (Xendit Integration)
Berdasarkan keputusan strategis, BIZETO akan menggunakan **Xendit** sebagai tulang punggung transaksi keuangan untuk pasar lokal dan regional.

### A. Metode Pembayaran yang Didukung:
*   **QRIS:** Untuk pembayaran instan via Bank (BCA, Mandiri, dll) dan E-Wallet (Gojek, OVO).
*   **DANA:** Integrasi langsung (Direct E-Wallet).
*   **PayPal & Wise:** Digunakan untuk pelanggan internasional melalui gateway pendukung.

### B. Teknis Integrasi (Backend):
1.  **SDK:** Menggunakan `github.com/xendit/xendit-go` pada Relay Server.
2.  **Schema Update:** Penambahan tabel `invoices` untuk melacak `external_id` Xendit dan status `PAID/EXPIRED`.
3.  **Webhook Handler:** Implementasi endpoint `/api/billing/webhook/xendit` dengan validasi token keamanan untuk otomatisasi aktivasi fitur user.

## 🔒 4. Hardening & Security (Zero-Trust Ready)
*   **Rate-Limiting:** Menerapkan middleware berbasis IP dan API Key (leaky bucket algorithm) untuk mencegah penyalahgunaan tunnel.
*   **DDoS Guard:** Integrasi dengan infrastruktur filter (misal: Cloudflare Spectrum atau Layer-7 filtering di Relay).
*   **Secret Management:** Migrasi seluruh API Keys ke sistem Vault terenkripsi.

---

## ⚡ 5. High Performance Protocol & DID (Phase 2 Upgrade)
Meningkatkan efisiensi komunikasi dan mengadopsi standar keamanan **Zero-Trust**.

*   **gRPC Bidirectional Streaming:** Mengganti JSON Handshake saat ini untuk mengurangi overhead TCP dan mendukung koneksi persisten yang lebih ringan.
*   **Decentralized Identifiers (DID):** 
    *   **Implementasi:** Mengganti pengiriman API Key statis dengan sistem tanda tangan digital privat/publik (Ed25519).
    *   **Keamanan:** Kredensial rahasia tidak pernah dikirim melalui internet. Agent membuktikan identitas melalui skema *Challenge-Response*.
    *   **Hybrid Mode:** Mendukung API Key konvensional untuk kemudahan UX awal dan DID untuk standar keamanan Enterprise.

## 🏢 8. Operational Integration (BIZETO-Omni Synergy)
Seluruh lini layanan pendukung akan diintegrasikan dengan platform **BIZETO-Omni** (folder `bizeto/`) untuk menciptakan ekosistem bisnis yang kohesif.

### A. Customer & Technical Support
*   **Embedded Omni-Widget:** Dashboard BIZETO-Tunnel akan menyematkan widget chat/tiket dari Omni untuk bantuan langsung.
*   **Diagnostic Sync:** Log kegagalan koneksi dari `bizeto-agent` dapat dikirimkan ke backend Omni sebagai tiket teknis otomatis, mempercepat proses *troubleshooting*.

### B. Sales & CRM
*   **Unified Customer Data:** Sinkronisasi profil user antara Tunnel dan Omni menggunakan Shared User ID untuk pemantauan *customer lifecycle*.
*   **Upgrade Trigger:** Setiap klik tombol "Upgrade" atau "Add Tunnel" (saat limit penuh) akan mengirimkan sinyal ke CRM Omni sebagai potensi *lead* bagi tim sales.

### C. Marketing Automation (via n8n)
*   **Event-Based Campaigns:** Pemanfaatan workflow **n8n** di folder `bizeto/n8n_workflows` untuk mengirimkan email edukasi otomatis berdasarkan penggunaan bandwidth user (misal: tips keamanan saat mencapai 1GB data).
*   **Subscription Reminders:** Notifikasi perpanjangan paket yang dikirimkan melalui saluran Omni-channel (WhatsApp/Email) terintegrasi.

## 🚀 9. Future Horizon (Advanced Inovasi)
Setelah stabilisasi v1.0.0, BIZETO akan berevolusi menjadi platform cerdas dengan integrasi teknologi berikut:

### A. Artificial Intelligence (The Smart Guardian)
*   **Anomalous Traffic Detection:** AI terintegrasi pada Relay untuk mendeteksi pola eksploitasi celah keamanan aplikasi lokal secara real-time.
*   **Predictive Maintenance:** Menggunakan machine learning untuk memprediksi kegagalan node dan otomatisasi load balancing antar wilayah.
*   **AI Diagnostics:** Asisten chatbot di dashboard yang membantu user melakukan debug konfigurasi firewall/port secara mandiri.

### B. Crypto & Web3 Billing (Powered by Avalanche)
*   **Avalanche C-Chain Integration:** Opsi pembayaran menggunakan AVAX atau stablecoin (USDC/USDT) di jaringan Avalanche untuk menjamin finalitas transaksi instan.
*   **BIZETO Subnet (The Global Secure Mesh):**
    *   **Apa:** Blockchain berdaulat khusus untuk ekosistem BIZETO guna mengelola traffic metadata dan Trust Layer secara terdesentralisasi.
    *   **Mengapa:** Memberikan isolasi total dari kepadatan traffic jaringan publik, memungkinkan penggunaan token kustom ($BZT), dan menekan biaya operasional metadata hingga mendekati nol.
    *   **Bagaimana:** Menggunakan konsensus Avalanche untuk memvalidasi identitas Agent dan memberikan reward otomatis bagi operator Relay melalui *Smart Contracts*.
    *   **Ending (Vision):** Transformasi menjadi jaringan konektivitas tanpa server terpusat (Decentralized Physical Infrastructure Network - DePIN), di mana keamanan dijamin oleh kriptografi blockchain dan ketersediaan jaringan dijamin oleh insentif ekonomi global.
*   **NFT Licenses (Avalanche):** Representasi kepemilikan paket Enterprise yang dapat diverifikasi secara transparan.

### C. Trust Layers (Zero-Knowledge Security)
*   **Decentralized Identifiers (DID):** Mengganti API Key dengan sistem tanda tangan digital privat/publik untuk menjamin identitas tanpa pengiriman kredensial.
*   **Hardware Attestation:** Memastikan biner agent dijalankan di perangkat yang belum dimodifikasi atau disusupi malware.
*   **Private Mesh Network:** Memungkinkan interkoneksi aman antar kantor cabang tanpa melalui gateway publik, menggunakan Trust Layer sebagai jembatan enkripsi.
